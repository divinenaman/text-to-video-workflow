# Grid Refinement Architecture Specification

## Overview
The Grid Refinement system acts as an autonomous visual self-healing loop for storyboards generated by AI image models. It combats "Continuity Drift" (e.g., wardrobe changes, facial identity loss) and "Spatial Hallucinations" (e.g., objects popping in, cloned background characters, warped scaling).

## Core Components

### 1. Initial Generation (`one-shot-image-grid`)
- **Purpose:** Generates a continuous cinematic storyboard (typically 8-9 panels) in a single image to maximize baseline visual consistency.
- **Constraints Applied:**
  - **Spatial Anchoring:** Maintains strict architectural geometry. If the camera rotates, the room layout must remain logical.
  - **Object Permanence:** Forbids spontaneous generation of large furniture (tables, thrones) mid-scene.
  - **Dynamic Crowds:** Strictly bans copy-pasted "clones" for background characters.
  - **No Split Screens:** Forces single cinematic frames; bans comic-book style diagonal dividers.

### 2. The Vision Judge (`holistic-grid-judge`)
- **Purpose:** Uses a high-capability Vision LLM (e.g., GPT-4o, Claude 3.5 Sonnet) acting as a 'Script Supervisor' and 'Forensic Spatial Auditor' to audit the generated grid against the original panel text descriptions.
- **Audit Criteria:**
  - **Identity & Wardrobe:** Checks for facial and clothing drift.
  - **Object Permanence:** Flags items that disappear or magically appear (e.g., extra tables).
  - **Anatomical Micro-Details:** Checks eye placement, fused fingers, and gaze logic.
  - **Formatting & Crowds:** Detects split-screens or cloned background characters.
  - **Positioning:** Checks for awkward scaling (giant heads) or floating characters.
- **Output:** Returns a JSON report with a `consistency_score` (0-100). If the score is below threshold (e.g., 90), it generates contextual 'Fix Directives' for each failed panel.

### 3. Surgical Refinement (`grid-refinement-v2`)
- **Purpose:** Re-prompts the image generator using the *flawed grid as a structural reference*, acting as a negative-prompt/inpainting engine to surgically apply the Fix Directives.
- **Execution Rules:**
  - **Build Upon:** Must use the provided grid as the absolute structural foundation.
  - **Surgical Accuracy:** Only deviates from the composition where explicitly requested.
  - **Erasure & Reconstruction:** If instructed to remove an extraneous object, must completely erase it and reconstruct the background seamlessly.
  - **Identity Lock:** Unaffected elements must remain 100% identical.

## Flow Execution
1. `create_image_grid` (in `processor.py`) generates the initial grid.
2. The grid is evaluated by `judge_image_grid`.
3. If it fails, `refine_and_fix_grid` is triggered.
4. The failed grid URL and the aggregated `fix_directive` list are sent back to the image generator (`image_gen`).
5. The generator produces a new, refined grid.
6. The process can repeat based on `refine_grid_count` (currently defaults to 1).
